3가지 모드:
1) Max Weight (기본, 현행) — 단일 세트 최고 중량
2) Single Set Volume — max(weight × reps) 한 세트
3) Session Volume — 한 세션 sum(weight × reps) 최대

Time-based (Plank) — 3 모드 모두 duration 기반 fallback.
Bodyweight (Pull-up 등) — Volume 모드에서 reps 기반 fallback (weight=0 이므로 volume 0 회피).
